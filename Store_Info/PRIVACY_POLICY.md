# Политика конфиденциальности

**Приложение:** Судоку Классик
**Версия документа:** 1.2
**Дата:** 2026-06-05
**Контакт разработчика:** terekhsupport@atomicmail.io

## 1. Какие данные мы собираем

Само приложение **не собирает и не передаёт никакие персональные данные** о пользователе. Игра работает полностью на устройстве: прогресс, настройки звука/вибрации и активный уровень сохраняются в локальном хранилище (`localStorage` WebView) на вашем устройстве и никогда не покидают его.

## 2. Реклама

В приложении используется рекламная сеть **Яндекс Мобильная Реклама** (Yandex Mobile Ads SDK). Реклама показывается:

- Между прохождениями уровней (interstitial).
- По вашему явному запросу (rewarded — восстановление сердца после проигрыша, +1 подсказка).

Яндекс Мобильная Реклама может собирать и обрабатывать данные, связанные с показом рекламы (идентификатор устройства для рекламы, версию ОС, страну, грубое местоположение по IP). Подробности — в политике конфиденциальности Яндекса:

- https://yandex.ru/legal/confidential/
- https://yandex.ru/legal/mobileads_sdk_agreement/

## 2.1. RuStore In-App Review SDK

Для возможности оценить приложение «не выходя из игры» подключён **RuStore Review SDK** от VK (компания «ВК»). SDK вызывается только по вашему явному действию — клику на кнопку «Оценить» в модалке «Нравится игра?» или в Settings. Сам SDK не собирает персональные данные сверх того, что уже делает приложение RuStore на устройстве. Контракт: JS-код вызывает диалог оценки → отображается нативный диалог поверх игры → пользователь ставит звёзды → диалог закрывается.

Подробности — в [политике конфиденциальности VK](https://vk.com/privacy) и [политике RuStore](https://www.rustore.ru/help/legal/).

## 2.2. Аналитика (Yandex AppMetrica)

Приложение использует SDK **Yandex AppMetrica** для сбора обезличенной аналитики:

- **Уникальный идентификатор устройства** (UUID, генерируется приложением, не связан с личными данными).
- **События использования**: запуски, выбор сложности, прохождение/проигрыш уровней, использование подсказок, ошибки в судоку, просмотр рекламы, открытие настроек.
- **Технические данные**: версия приложения, версия Android, модель устройства.
- **Часовой пояс, язык, страна** (по IP, IP не сохраняется).
- **Crash-репорты**: при сбое приложения отправляется stack trace для диагностики.

Данные передаются на серверы ООО «Яндекс» (РФ) и используются для:
- анализа поведения пользователей и улучшения приложения;
- подсчёта аудитории, ретеншена, конверсии;
- выявления ошибок и сбоев.

**Персональные данные** (имя, email, номер телефона, точная геолокация) **не собираются**.

Подробнее: [Политика конфиденциальности Yandex AppMetrica](https://yandex.ru/legal/confidential/).

## 2.3. Push-уведомления (локальные)

Приложение показывает локальные push-уведомления (напоминания о возврате). Реализованы через Android `AlarmManager` **локально на устройстве** — никаких токенов или серверов рассылок не используется. Можно отключить в системных настройках Android.

## 3. Cookies / Tracking

Приложение не использует cookies (это не веб-приложение). Сторонние внешние сервисы аналитики (Firebase, Google Analytics) **не подключены**. Единственная подключённая аналитика — Yandex AppMetrica, описанная в разделе 2.2.

## 4. Хранение данных

Все игровые данные (прогресс, настройки) хранятся в локальном хранилище приложения на устройстве. При удалении приложения они удаляются вместе с ним. Никаких облачных синхронизаций нет.

## 5. Возрастные ограничения

Приложение не имеет возрастных ограничений по содержимому (0+).

## 6. Права пользователя

Вы можете:
- Удалить локальные данные через настройки Android (Приложения → Судоку Классик → Очистить данные).
- Удалить само приложение.
- Связаться с разработчиком по адресу **terekhsupport@atomicmail.io** по любым вопросам.

## 7. Изменения политики

Эта политика может обновляться. Актуальная версия всегда доступна по тому же URL.
